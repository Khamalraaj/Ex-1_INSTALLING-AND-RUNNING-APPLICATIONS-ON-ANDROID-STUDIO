Step 1 – System Requirements

Android Studio is used to develop and run Android applications. Java is used to write the application code, and Firebase Realtime Database stores application data online.

Required Software

- Android Studio
- Java Development Kit (JDK)
- Android SDK
- Firebase Console
- Android Emulator or Mobile Phone

Step 2 – Setup Android Studio

Android Studio is the official development environment used to create Android applications.

Installation Procedure

1. Install Android Studio.
2. Open Android Studio and create or open a project.
3. Select Java as the programming language.
4. Design the application interface and write the Java code.

Connecting Firebase

1. Open Firebase Console and create or select a project.
2. Register the Android application using its package name.
3. Add "google-services.json" to the "app" folder.
4. Add the Firebase Realtime Database dependency.
5. Create a Realtime Database.
6. Add internet permission in "AndroidManifest.xml".
7. Connect the application to Firebase.

Creating the Contact Manager Application

1. Add fields for contact name and email.
2. Add buttons to add, view, update, and delete contacts.
3. Store contact details under the "contacts" node.
4. Display the saved contacts in the application.

Step 3 – Run the Application

1. Open the project in Android Studio.
2. Connect an Android phone or start an emulator.
3. Select the device and click the Run ▶ button.
4. Add a contact and check that it appears in the application.
5. Open Firebase Console and verify the saved data.
6. Test updating and deleting contacts.
